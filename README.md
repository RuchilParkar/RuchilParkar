**AI-powered writing transformation platform**

A web application designed to transform AI-generated text into more natural, human-like writing through multiple AI providers and intelligent fallback handling.

- AI-powered text transformation.
- Multi-provider AI architecture.
- Groq, Gemini and OpenRouter integrations.
- Backend API handling and validation.
- Rate limiting and abuse protection.
- Responsive, modern Neo-Brutalist interface.

**Tech Stack:** Next.js, TypeScript, Groq, Gemini, OpenRouter, Upstash Redis, Tailwind CSS.

- Progressive difficulty.
- Multiple environments and themes.
- Day-night transitions.
- Parallax backgrounds.
- Collectibles, credits and power-ups.
- Custom audio effects.

**Tech Stack:** HTML, CSS, JavaScript, HTML5 Canvas, Web Audio API.
